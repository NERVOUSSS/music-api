# 音乐 API 与在线音乐平台

这是一个带有后台管理、官方音乐平台账号授权、自定义音源和在线播放器的音乐服务项目。项目支持网易云音乐、QQ 音乐、酷狗音乐、咪咕音乐等目录搜索，以及歌曲播放地址、歌词、歌单、收藏、播放列表和多音源回源。

## 运行环境

- Python 3.10 或更高版本
- Node.js LTS：仅网易云音乐二维码登录功能需要

## Windows 启动

双击项目根目录中的 `start-music-api.bat`。启动脚本会自动创建 Python 虚拟环境、安装依赖，并在需要时安装网易云二维码登录适配器。

默认地址：

- 在线音乐平台：`http://127.0.0.1:8100/music`
- 用户注册和登录：`http://127.0.0.1:8100/register`、`http://127.0.0.1:8100/login`
- 后台管理：`http://127.0.0.1:8100/admin`
- API 文档：`http://127.0.0.1:8100/docs`

如果后台配置中的端口被修改，请以实际配置端口为准。

## Linux 或 macOS 启动

在项目根目录执行：

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python server.py
```

服务器对外部署时，建议使用 Nginx 或其他反向代理，并配置 HTTPS。不要直接把开发服务端口暴露到公网。

## 首次部署

1. 打开 `/register` 注册账号。
2. 第一个注册的账号会自动成为管理员。
3. 使用管理员账号打开 `/admin`。
4. 在后台配置官方音乐平台授权、自定义音源和其他服务参数。

项目首次运行后会在 `data/` 目录生成运行数据，包括用户、登录会话、歌单、收藏、Cookie、Token、日志和服务配置等。

## 插件点歌接口

原有点歌接口继续可用；咪咕音乐另外提供独立入口，返回字段与插件使用的 `/api/wxmusic` 一致：

```text
GET /api/migumusic?keyword=歌名&key=你的_API_Key
```

也可以在统一接口中指定咪咕：

```text
GET /api/wxmusic?source=migu&keyword=歌名&key=你的_API_Key
```

返回 `code`、`title`、`singer`、`cover`、`link`、`music_url` 和 `lyric`。若没有设置 API Key，可省略 `key` 参数。咪咕未在官方目录响应中提供播放地址时，`music_url` 会为空，不代表可绕过会员、地区或版权限制。

## 自定义音源

项目自带的音源脚本位于 `音乐音源/` 目录。可以在后台管理中检测、启用或停用兼容的音源。

咪咕音乐搜索使用其公开目录响应；仅在官方响应明确提供可播放地址时才会直接播放。未提供地址的歌曲仍会遵循会员、地区和版权限制，并可按后台已启用的合法回源配置尝试播放。

上传或添加第三方音源前，应确认来源合法，并遵守对应平台的服务条款和版权规定。项目不会因为添加音源而绕过歌曲的会员、地区或版权限制。

## 数据与安全

`data/` 中保存的是部署实例的个人运行数据，不能提交到 GitHub。发布版本只保留：

```text
data/.gitkeep
```

部署到新服务器后，需要重新注册账号并重新配置各平台授权。不要把以下内容提交到公开仓库：

- 用户密码数据和登录会话
- 音乐平台 Cookie、Token、API Key
- 用户歌单、收藏和绑定账号
- `.venv/`、`.ncm-qr-adapter/`、`node_modules/`
- 日志、备份文件和缓存文件

项目中的 `.gitignore` 已经配置了这些运行数据和本地依赖的忽略规则。若历史提交中曾经包含过密码、Cookie 或 Token，仅删除当前文件还不够，还需要清理 Git 历史并更换相关凭据。

## GitHub 发布与部署

可以直接上传当前源码目录，或在 GitHub 上创建仓库后执行：

```bash
git init
git add .
git commit -m "初始化音乐平台项目"
git branch -M main
git remote add origin <你的仓库地址>
git push -u origin main
```

其他人克隆项目后，按照上面的 Windows 或 Linux 启动步骤安装依赖即可。每个部署环境都会拥有独立的用户、授权和配置数据。

## 主要目录

```text
server.py          后端服务与 API
music_sources.py   音源配置与公共逻辑
qishui_adapter.py  汽水音乐相关适配代码
static/            在线音乐平台和登录页面
音乐音源/          自定义音源脚本
data/              本地运行数据，不应提交
```
